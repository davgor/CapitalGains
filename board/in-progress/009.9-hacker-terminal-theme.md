# 009.9 — Black/green hacker terminal theme

Restyle the CapitalGains dashboard UI as a black-and-green terminal/hacker aesthetic so the Phase 3 shell feels cohesive and on-brand for an ops console. Applies across header, factory rows, stage chips, modals, settings, and analytics.

## Acceptance criteria

- [ ] Global CSS variables use a dark terminal palette (near-black background, phosphor green ink/accent) with a purposeful mono/display font stack (not Inter/Roboto/system-only)
- [ ] First viewport reads as one composition: brand `CapitalGains` is hero-level, with Daily Limit / Profit and primary factory surface — not a flat light marketing page
- [ ] Stage greys, failed, and active states remain distinguishable under the dark theme
- [ ] Existing auto-update banner/controls remain usable and themed consistently
