# 007.4 — Feature tape + universe filters

Before any ranking, code builds a candidate tape with computed features (premarket gap %, RVOL, ADV, market cap, price, sector, spread estimate) and hard filters: ADV > 1M, mkt cap ≥ $2B, price ≥ $10, no 3× leveraged ETFs unless explicitly allowed.

## Acceptance criteria

- [ ] `buildFeatureTape(asOf)` returns only universe-passing symbols with feature fields
- [ ] Unit tests reject penny / illiquid / micro-cap / leveraged-ETF names
- [ ] Tape is serializable into the store for Research modal replay
- [ ] Depends on 007.3 for underlying quotes/fundamentals fixtures
