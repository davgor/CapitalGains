# 007.6 — Risk engine

Mandatory risk: max single-name weight, max sector weight, default stop-loss %, portfolio daily loss halt (flatten + block further buys). Research may tighten stops, not remove them (unless SitOut).

## Acceptance criteria

- [ ] `validateBasket(allocations, limits)` rejects over-name / over-sector / over-sum weights
- [ ] Monitor path triggers stop flatten when mark breaches stop from fill
- [ ] Daily loss halt flattens remaining and sets a session flag blocking new buys (unit-tested)
- [ ] Defaults configurable via settings object (wired in UI later in 009)
