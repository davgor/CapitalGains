# 007.9 — Idempotent resume + infra_skip

Restart mid-monitor or mid-flatten must not double-fill or double-log. Purchases keyed for idempotency. Missed windows / hard failures set `infra_skip` so later promote stats (009) can exclude them.

## Acceptance criteria

- [ ] Replaying “place basket” after a committed fill is a no-op (unit-tested)
- [ ] Resume loads last committed stage and continues without resetting P&L
- [ ] `infra_skip` flag settable and queryable on sessions
- [ ] Test simulates crash between fill persist and stage advance
